# Seatway

Ticket booking with a stop on the way, for older travellers in Poland.
University UX project – Mohamed Eisa and Ahmed Mohamed.

| Folder | Version | Description |
|--------|---------|-------------|
| `app_version_0` | 0 | First prototype: one HTML page with sample trips, search, name validation and an in-memory reservation list (HTML, CSS, JavaScript) |
| `app_version_1` | 1.1 | Full application: 10 screens, stops on the way, Spring Boot REST API, PostgreSQL; includes the corrections from the Class 8 usability evaluation |
| `app_version_2` | 2 | Version 1.1 plus a Polish / English language switch |
| `app_version_3` | 3 | Version 2 plus a simulated payment step with a confirmation check |

To run version 1, 2 or 3, open its folder and follow its README.
